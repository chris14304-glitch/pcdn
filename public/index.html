Resources & Utilities

Curated tools and resources for testing, analyzing, and improving your security posture.

IC3

If you or someone you know has suffered a scam or another internet related crime such as extortion, phishing, fraud, ransomware, hacking, identity theft, predation, harrassment, and so much more ... report it to the FBI at https://www.ic3.gov/

Visit IC3.gov

OWASP

The Open Web Application Security Project — the leading resource for web application security standards, testing guides, and the OWASP Top 10 vulnerability list.

Visit owasp.org

Security Headers

Scan any website to analyze its HTTP security headers. Check for Content-Security-Policy, HSTS, X-Frame-Options, and other critical headers that protect against common attacks.

Visit securityheaders.com

Wireshark

Wireshark lets you dive deep into your network traffic - free and open source

Visit wireshark.org

Brave Web Browser

Block ads. Save data. Get way faster web pages. Just by switching your browser.

Visit brave.com

Burp Suite

Burp Suite is a web application security testing tool used by cybersecurity professionals and bug bounty hunters to inspect, intercept, and modify web traffic between a browser and a website. It allows users to analyze HTTP requests and responses, test for vulnerabilities like authentication flaws or input validation issues, and better understand how web applications work. The Community Edition is free and widely used for learning web security and practicing bug bounty hunting.

Visit portswigger.net

Static Code Analyzer

PCDN's static analysis tool for scanning source code for security vulnerabilities, code quality issues, and potential weaknesses before they reach production.

Launch analyzer

Memory Purge Utility

PCDN's Memory Optimization tool. A lightweight utility for purging cached memory and temporary data from your system. Helps maintain performance, clean junk files, and basic antivirus scanning capabilities.

Disk Drive Analytics

PCDN's disk drive analytics tool. A lightweight utility for Windows — SMART, partitions, filesystem validation, a hex viewer, raw signature carving, USB descriptors, and event-log correlation behind a single 'Investigate' button that produces a case report.

Download StorageInvestigator.zip

HEIC to JPG Converter

Troubleshooting Assistant

Download Troubleshoot Assist.zip

Image Metadata Extractor

Download Image Metadata Extractor.zip

Network Scanner

PCDN's Python Network Scanner. Scan open ports on your local network to monitor what's exposed on your WiFi and spot potential vulnerabilities.

Download Network Scanner.zip

Autoclicker

PCDN's Python Autoclicker. This autoclicker made available for use so you don't have to visit sketchy/untrusted sites or download sketchy programs in order to get an autoclicker.
